# domain-driven-transformation.org

The website for *Domain-Driven Transformation* by Carola Lilienthal and Henning Schwentner

## Development

### Setup environment

Install Rancher Desktop on Windows:

```pwsh
\$ winget install -e --id suse.RancherDesktop
```

Install Rancher Desktop on macOS:

```fish
\$ brew install --cask rancher
```

### Day-to-day Development

Open the project as a dev container and directly start the server:

```fish
\$ bundle exec jekyll serve
```
